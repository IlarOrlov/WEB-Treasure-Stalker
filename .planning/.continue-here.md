## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Judging hub links by the hub URL | `/category/2-sezon/` has no title words, so its episode links were dropped | blocking | `related_links()` judges against start URL + `series_tokens()` of known episode links |
| Over-broad ad blocking | interkh.com was blocked as an ad, but it served rewall's real manifests | advisory | Only block known tracker/ad hosts in `TRACKER_RE`; validate by playing on real sites |
| Accepting the first "stream" | vibix/rewall manifests looked fine but were unusable | blocking | `_manifest_ok()` checks the body (#EXTM3U / MPD) and that referenced hosts resolve |
| Tab group misdetection | tab bar + content panel picked instead of the tab buttons | advisory | `_PLAYER_TABS_JS` requires siblings with the same tag and first class |
| Partial cleanup under concurrency | snapshot-diff cleanup could delete other downloads' partials | blocking | `_remove_partials(touched)` uses only files reported by this download's progress hook |

# BLOCKING CONSTRAINTS — Read Before Anything Else

> Each constraint below was discovered through failure. Acknowledge each one before proceeding.

- [ ] CONSTRAINT: verify tests before committing. A chain like `pytest | tail -1 && git commit` committed and pushed a failing build once (tail returns 0). Use `set -o pipefail` (or check the exit code) before any commit, push, or CI trigger.
- [ ] CONSTRAINT: never delete a folder the user may be running from. `rm -rf ~/Desktop/WEB-Treasure-Stalker-test` ran while the user's app was running from it. Download into a temp folder (`~/Desktop/.wts-test-incoming`) and swap only when complete.
- [ ] CONSTRAINT: no circumvention of protection. Do not write decoders for obfuscated player playlists or token-signed streams (Alloha/userplay.live), and do not record streams from the browser. Detect them, label them "protected", and try other players.
- [ ] CONSTRAINT: `pkill -f <pattern>` matches its own shell command line and kills the shell (exit 144). Find PIDs with `ps -eo pid,args | grep "[p]attern"` and kill those instead.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Label-crediting by time | Streams that arrive late, or from another player, got credited to the wrong episode | blocking | Credit only stream URLs new since the click AND requested by the same player (referer host == frame host) |
| Stale DOM markers | Player re-renders its lists, so `data-wts-pm-*` markers vanish and clicks silently fail | blocking | Re-run `_PLAYER_MENU_JS` (re-mark) before every season/episode click |
| Over-broad heuristics | S01E03 regex matched random tokens in stream URLs; "page season" remap mislabelled berserk | advisory | Require delimiters; keep the player's own numbering; validate on real sites (Mentalist x2, Good Doctor, berserk, yummyanime, filmlord) |
| yt-dlp id archive | All episodes from a player get the generic id "hls", so the archive skipped them as duplicates | advisory | Episode/item downloads use `use_archive=False` |
